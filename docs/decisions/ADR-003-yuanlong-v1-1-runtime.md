# ADR-003: 元珑 V1.1 Agent 运行时契约

日期：2026-08-21
状态：已采纳

## 背景

《元珑人格画像与 AI 行为宪法 V1.1》与验收对话测试集明确了元珑的角色、知识状态、安全分级、记忆边界和 45 条验收用例。此前核心仅具备通用 Agent 框架，不能直接证明这些规则在运行时被执行。

## 决策

1. 以严格 JSON 合同承载每次对话的年龄段、能力快照、公开场景标记、儿童确认状态、事实来源与上报安全码；缺字段即拒绝请求。
2. 先走确定性安全路由，再调用模型。S1 至 S4 会直接给出受控回复，模型不会看到这类输入。
3. 知识回答统一标记为 K0 至 K4。只有 K0 能引用审核事实；K1/K2 必须引用本轮观察；K3/K4 不得伪装为已知。
4. 每次正常对话最多调用并引用一条普通、未过期、同一家庭/儿童档案/元珑实例的记忆。敏感记忆不会进入模型上下文。
5. 记忆只能来自儿童明确确认过的文本表达，且只能写入普通等级；更新既有记忆使用 replace，旧记录会软删除。
6. 保留验收工作簿中的 45 条案例及 165 次计划运行数为代码夹具；其中所有安全案例均有不经模型的自动化回归。

## 后果

- 任何前端、玩偶或后端调用方都必须传入完整请求，不存在静默兼容旧请求的路径。
- 正式知识库、长期记忆数据库和家长端处置流程仍由服务层实现；核心只定义并强制它们的输入输出边界。
- 本 ADR 记录产品运行时决策；个人代码导览与解析文档保持本地忽略，不进入组织仓库。
